# TimeRush ⏱️

TimeRush is a mobile quiz application developed in Flutter, designed to help students and general users test their knowledge across multiple subjects in a fun and time-pressured environment. 

The core concept is straightforward: pick a subject, select a difficulty level, and race against a per-question countdown timer to answer as many questions correctly as possible. The application features a clean, dark-themed UI that keeps you focused on the questions rather than the interface.

---

## ✨ Key Features

**Core Gameplay & Mechanics**
* **Time-Pressured Quizzing:** Answer questions while racing against a strict, per-question countdown timer.
* **Straightforward User Flow:** A simple, seamless 3-step process: Select a subject ➔ Choose a difficulty level ➔ Start the quiz.
* **Skill-Building:** Designed to reward quick thinking and test knowledge retention under pressure.

**Categories & Content**
* **Multiple Subjects:** Test your knowledge across seven distinct categories: Biology, Math, Science, Chemistry, English, Physics, and Geography.
* **Adjustable Difficulty:** Choose between **Basic** and **Standard** challenge tiers to accommodate your learning stage and capabilities.
* **Broad Audience:** Built for both students looking to study and general users looking for a fun trivia challenge.

**Design & Technology**
* **Focus-Driven UI:** A clean, visually polished dark-themed interface specifically designed to eliminate distractions.
* **Built with Flutter:** Smooth, high-performance experience utilizing custom Flutter widgets.

## 🚀 How to Run the Project Locally

Follow these steps to get the project running on your local machine:

## 1. Clone the repository:**
```bash
git clone [https://github.com/Soniya1239/TimeRush.git]
```
## 2. Open the project:
Open the cloned folder in your preferred code editor (e.g., Visual Studio Code or Android Studio).

## 3. Install dependencies:
Open your terminal inside the project folder and run the following command to fetch the required packages:

```Bash
flutter pub get

```
## 4. Run the app:
Connect a physical device or start an emulator, then run the application:

``` Bash
flutter run
```
